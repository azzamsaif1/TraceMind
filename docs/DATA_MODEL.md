# Data Model

All primary keys are UUID strings. Timestamps are timezone-aware UTC. JSON
columns store structured evidence/score/manifest payloads. Defined in
`rusted_recall/models.py`.

## Entities

| Table | Purpose | Key relationships |
| --- | --- | --- |
| `workspaces` | Tenant / campaign container | parent of assets, sources, recalls |
| `source_of_truth_items` | Canonical items (package, claim, price, licensed face/voice) | has many versions |
| `source_of_truth_versions` | Immutable version of a source item (label, claim text, reference hashes, B2 key) | belongs to item |
| `assets` | A media asset (hero ad, social post, …) | has many versions; optional `parent_asset_id` |
| `asset_versions` | **Immutable** version (sha256, phash, dims, B2 keys, `origin=uploaded\|repaired`, `parent_version_id`) | belongs to asset |
| `artifact_objects` | Every B2 object created (key, kind, sha256, size, backend) | per workspace |
| `dependency_edges` | Evidence-bearing edges (`source_node`/`target_node` as `sot:<id>`/`asset:<id>`, type, confidence, evidence_details, algorithm_version, human_confirmed) | per workspace |
| `analysis_runs` | An impact analysis execution (model + config hash) | per recall |
| `recall_events` | A change event referencing exact old/new source versions; status machine | belongs to workspace |
| `recall_impacts` | Per-asset classification + `score_components` + `reasons` + `strongest_path` | per recall |
| `review_decisions` | Human decisions (approve/exclude/mark_safe/reclassify) | per recall+asset |
| `repair_plans` | Deterministic plan stored **before** execution (idempotency key, plan JSON, B2 key) | per recall+asset+version |
| `repair_jobs` | Durable job state (`queued→running→completed\|failed\|requires_review`) | references plan |
| `generation_runs` | Provider/model/pipeline attempt log per job | per job |
| `validation_results` | Output validation checks + human-review flag | per job+version |
| `audit_events` | **Append-only** log of every state change | per workspace/recall |
| `provider_configurations` | Registered providers (primary/fallback, model, enabled) | — |

## Invariants

- **Immutable asset versions.** No update path rewrites pixels; a repair inserts
  a new `asset_versions` row with `origin=repaired` and `parent_version_id`
  pointing at the source version.
- **Originals never overwritten.** Repaired output is stored under a distinct
  `repaired/...` B2 key; the original `assets/.../original/...` object is left
  intact and its existence is asserted in tests.
- **Append-only audit.** `audit_events` rows are only inserted, giving a full
  causal timeline that the final report renders.
- **Exact hashes preserved.** `asset_versions.sha256` and `.phash` store the
  precise values computed at ingestion and after repair.

## Lineage chain

```
source_of_truth_version
  → dependency_edge (evidence)
    → asset / asset_version (original)
      → recall_event (old_version → new_version)
        → recall_impact (score components, path)
          → repair_plan (idempotency key)
            → repair_job → generation_run (provider/model/pipeline)
              → asset_version (repaired, parent_version_id)
                → validation_result
                → manifest (B2) linking all of the above
                  → audit_events (append-only)
```

## B2 object namespace

```
rusted-recall/workspaces/{workspace_id}/
  source-of-truth/{item_id}/versions/{version_id}/original/{filename}
  assets/{asset_id}/versions/{version_id}/original/{filename}
  assets/{asset_id}/versions/{version_id}/preview/{preview}
  assets/{asset_id}/versions/{version_id}/analysis/analysis.json
  recall-events/{recall_id}/plans/{repair_plan_id}.json
  repaired/{asset_id}/versions/{new_version_id}/output/{filename}
  repaired/{asset_id}/versions/{new_version_id}/validation.json
  repaired/{asset_id}/versions/{new_version_id}/manifest.json
```

Object keys are generated by `ObjectKeys` (`rusted_recall/storage/base.py`).
